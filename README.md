# Dhiraj Nimje — Portfolio

Personal portfolio site for **Dhiraj Nimje**, AI & Machine Learning Engineer working in computer vision, NLP, and retrieval-augmented generation.

🌐 **Live site** → [jerry11-tech.github.io/portfolio](https://jerry11-tech.github.io/portfolio/)

---

## Features

- **Hero** with animated intro and particle background
- **Boot sequence** loader for a polished first impression
- **Command palette** (`Ctrl/⌘ + K`) for fast keyboard navigation
- **Recruiter view** — a condensed, ATS-friendly summary mode
- **AI assistant** panel built into the site
- Fully responsive, dark/light aware

## Stack

| Layer | Choice |
|---|---|
| Build | [Vite](https://vite.dev) |
| UI | [React](https://react.dev) 19 |
| Styling | [Tailwind CSS](https://tailwindcss.com) |
| Icons | [lucide-react](https://lucide.dev) |
| Language | JavaScript (ESM) |

## Getting started

```bash
git clone https://github.com/jerry11-tech/portfolio.git
cd portfolio
npm install
npm run dev      # start dev server on http://localhost:5173
```

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Build to `dist/` |
| `npm run preview` | Preview the production build locally |
